# Terminal Basics: Command Line Cheat Sheet 🖥

## Common Command Line Commands
#1 - `mkdir`: Used to *create* a folder📁 to contain files or other folders, including a customizable name

Example:

  `mkdir folder_example1`

---
#2 - `touch`: Used to *create* a file🗃 like .md or .txt inside a folder of your choice

Example:
```
  `touch file_example1.md`
  

  `touch file_example2.txt`
```

  ---

#3 - `list`: Also known as ls is Used to *list*🔢 *all* all current *folders* in the directory

Example:

  `ls`

  Output: folder_example1  file_example1.md  file_example2.txt

---
#4 - `cd`: Used to *enter* a folder that is specified ⇉

Example"

  `cd folder_example1`

---
#5 - `pwd`: Used to *see* your current location 🔻

Example:

  `pwd`

  Output: /workspaces/folder_example1

---
- cd has a secondary type: cd . . which is used to **go back** ⇇ to a directory rather then into a folder
- mkdir has a secondary type: rmdir which is to **remove**🫥 a empty file of the name of you're folder
